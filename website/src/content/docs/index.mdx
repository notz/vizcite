## Install

<Tabs>
  <TabItem label="One-liner">
```bash
curl -fsSL https://vizcite.com/install.sh | bash
```
  </TabItem>
  <TabItem label="Docker Compose">
```bash
docker pull ghcr.io/notz/vizcite
```
Compose files and `.env` live in [`deploy/`](https://github.com/notz/vizcite/tree/main/deploy).
  </TabItem>
</Tabs>
